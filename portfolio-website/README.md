# Faeiz Furqan — Portfolio

Personal portfolio of Faeiz Furqan, a full stack web & mobile app developer. Built with Next.js (App Router), MUI, and Framer Motion.

## Stack

- **Framework:** Next.js 15 (App Router)
- **UI:** MUI (Material UI) + Tailwind CSS v4 theme tokens
- **Motion:** Framer Motion
- **Language:** TypeScript

## Development

```bash
npm install
npm run dev
```

## Structure

- `src/app/HomeContent.tsx` — hero + page composition
- `src/app/components/` — Experience, Skills, Projects, Certifications, NavBar, Footer
- `src/app/context/ThemeContext.tsx` — light/dark theme provider
- `src/app/globals.css` — design tokens (colors, radii, shadows) per theme
